# 📚 Catálogo de HQs e Mangás

Este é um sistema web simples para cadastro e visualização de HQs e mangás. Criado como projeto de estudo com PHP puro, HTML e CSS.

---

## 🔧 Funcionalidades

- ✅ Visualizar todos os títulos cadastrados
- 🔍 Filtrar por título ou categoria
- 🔐 Área de login (usuário fixo: `admin`)
- 📝 Cadastro de novos títulos (somente para usuários logados)
- 📌 Login persistente (usuário permanece logado mesmo após fechar o navegador)
- 🚪 Logout seguro
